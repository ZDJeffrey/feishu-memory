# Agent 协作

主 Agent 启动同步无需预先读取远端路由规范：显式指定 `gpt-6.1-terra`、`medium`，传递 feishu-memory 已启用、目标空间、已有本地副本位置和验收条件。接收同步任务的 Terra 直接执行，不再次分派启动同步；其他子 Agent 复用父任务已同步的副本。Terra 完成同步后只返回状态、相关页面和异常。

远端 pull、飞书 CLI、写回、冲突与结构核对、画板绘制及渲染均由 Terra 执行，复杂状态按需使用 `high`。主 Agent 负责目标、内容与图示语义、工作副本编辑、关键判断和验收。已同步且未变化的规范及其版本在同一会话复用；子 Agent 获取任务所需的规范入口和章节，复用副本，无需再次同步整库。

创建时显式指定实际模型与 effort，名称包含实际模型名；使用独立小上下文时传递目标、范围、已启用状态、必要事实、规范入口、工作目录和验收条件。每个任务覆盖完整的执行与验证，Terra 在阶段完成、异常或需要决策时通知，最终返回结果、版本、验证和待解决事项。飞书草稿、中间资源与预览放在项目外的系统临时目录。

依赖子任务且暂无独立工作时，调用 `wait_agent({timeout_ms: 60000})`；消息、完成事件或用户新输入可提前唤醒，超时后直接续接等待，不额外查询状态、读取日志或发送无变化消息。若运行器限制短于 60 秒，以允许的最长时限等待；没有事件等待接口时，按 60、120、300 秒逐步延长查询间隔，之后维持 300 秒。最终回复会结束本轮，后续自动恢复取决于运行器是否提供独立的持久任务和唤醒机制。
