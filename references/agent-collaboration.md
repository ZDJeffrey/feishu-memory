# Agent 协作

按记忆空间“模型能力与任务分配”的路由与 effort、分派与验收章节选择模型和档位，提供任务目标、范围、适用规范和验收标准。子 Agent 继承启用状态时，明确传递该状态与父任务已同步的本地副本位置。

涉及飞书文件生成时，传递 [本地工作目录](operations.md#本地工作目录) 约定：命令从项目外的系统临时目录运行，草稿和中间资源保存在该处。

子 Agent 名称应包含实际使用的模型名，如 `astra`、`terra`、`luna` 或 `sol`，便于识别执行者。

创建时显式指定实际模型与 effort；选择不同模型且工具要求独立上下文时使用 `fork_turns=none`，传递完成任务所需的上下文。可用模型与参数以当前工具为准。

依赖子任务且没有独立工作时，使用运行器的事件等待；等待期间不循环查询 Agent 状态或读取日志。等待时长、超时和通知按记忆空间“模型能力与任务分配”的等待与通知章节执行。
